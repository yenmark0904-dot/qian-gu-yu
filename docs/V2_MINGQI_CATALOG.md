# 命器總表（27 種）

資料來源：15 件專屬＝`docs/V2_USER_MINGQI_15_OFFICIAL.md`（t360u 原文，名稱與文案逐字搬入 `src/game/artifacts.ts`）；12 件通用＝t359u 鎖定名稱與初版測試數值。所有數值為**第一版平衡測試值**，集中於 `artifacts.ts`（觸發次數、倍率、覺醒倍率、替代效果）與 `artifact-engine.ts ARTIFACT_LIMITS`（全隊上限）。

所有 65 位角色都可裝備任一命器；通用 S／R 命器沒有專屬層；專屬層只在「裝備者角色 ID ＝ exclusiveCharacterId」時啟動。

## 統一引擎規則（程式已強制）
- 只讀「玩家正常移動」產生的消除波；角色技能的橫掃／火燒波與命器效果本身不進引擎 → 不可能自我觸發。
- 特殊玉以「實際引爆」計（波內 row／col／bomb／color 效果），不在生成時計算。
- 同一波多件命器的加成總和上限 +60%（全隊）；每步命器加分上限 400。
- 蓄力只給裝備者本人、只來自玩家移動的第一波（直接消除），每人每關上限 8；技能、命器、連鎖不產生蓄力。
- 專屬：原主人發動自己的原技能後待發；觸發一次即消失；重複發動只刷新、不疊層；未觸發則 5 次玩家移動後失效；每人每關最多 6 次。
- 命器只加分數／蓄力，不加步數、不加墨玉、不動緣分與技能；劉徹星賞墨玉規則未改。
- 等級曲線（Lv.1→Lv.10 差距比例）：0, .10, .20, .30, .45, .55, .65, .75, .85, 1（單調不降）。專屬技能 Lv.1–9 固定，Lv.10 才升為覺醒值。
- 專屬命器的通用被動官方只給 Lv.1 值；Lv.10 暫訂 Lv.1 × 1.5（`GENERAL_GROWTH`，待確認）。
