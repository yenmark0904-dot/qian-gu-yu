# V1.3 墨厄討伐（獨立模式）

入口：故事與闖關 → 三消地圖 →「墨厄討伐 · 三人助陣」。不影響主線門檻。

## 共用與隔離
- 原有 `match3.ts` / `assist.ts` / `skills.ts` 原樣共用；原 50 關、150 星、塔與召喚無規則修改。
- `raid.ts` 是獨立純戰鬥狀態／Boss 傷害層，不是另一個三消引擎。
- 顯示元件沿用 Match3 的玉石、龍珠、特殊玉爆炸和 SkillButton。角色圖片缺失使用 Portrait 的字印 fallback，不檢查完整立繪。
- `raid: { team, records }` 為追加存檔，使用原 zustand persist 和 Snapshot 雲端同步。舊版缺省空值。首賞標記與墨玉同一次 set 提交；雲端採用時保留已領標記。
- 戰鬥是短局，暫不存中場棋盤；撤回／重新載入不扣資源，免費重新開局。介面已明示。

## 集中平衡配置
Boss 表 `RAID_BOSSES`：噬墨之影 5000 HP、20 步；每 3 次有效玩家移動生成 2 墨封並設 95 護盾；HP 低於 50% 進二階，下次反擊多 1 冰封。最多 10 處封印，任何單一封印若會封死最後有效交換即回退。保留原洗牌，極端全封測試亦可恢復。

`RAID_RULES`：每玉 27 傷害，連消每階 +25%（最高 +200%），每特殊爆炸 +65，每破封命中 +24；一般技能另 +90。消玉先每顆削盾 10，剩餘盾再吸收傷害。得分型技能在討伐增幅傷害，持續增益只取最強，絕不相乘。

既有星賞加成型技能在討伐轉為**首次討伐獎勵**加成，最多 +50%，只取最強。首勝基本 300 墨玉，最多 450；重複勝利 0。地圖星賞公式完全不變。

每位角色使用原 chargeCost（R55 / S65 / SS85 / SSR75；貳×.92／參×.84）獨立蓄勢。只有有效玩家移動回充，每回合上限22能量。技能造成的消除、連攜均不回充。全隊一局最多額外12步（最多32次有效玩家移動），杜絕爆炸及三人加步循環。技能及連攜不耗步。

雙人：20秒且1次玩家移動以內，兩位不同角色施放，額外240傷害、削盾100；第三位不同角色：天命共鳴，額外520傷害、削盾220。同一人重複施放重開窗口，三人完成後亦須重新組鏈。所有稀有度通用。

## 呈現與效能
CSS 墨影、受擊、傷害浮字、玉能飛襲、特殊玉強化、雙／三人 cut-in、墨氣反擊、消散與獨立結算。技能顯示原技能 flavor 並播放既有角色語音，不新增主線或情話。

略過技能、點 cut-in 略過、減少特效、省電模式；尊重 prefers-reduced-motion，雙核心以下預設省電。已驗證 390×844、375×667、1280×900 操作區不需捲動，前兩者玉格約53px／47px。小於約600px的極短視窗物理高度有限，保留44px玉格優先。

## 美術
Boss 是可運作的CSS墨氣剪影；尚無專屬Boss原畫、Live2D、指定組合專屬配音。65人均不因缺立繪阻擋遊玩。沒有新增「待你撰寫」或涉及月身分的文本。

完整現有 game 測試 225/228 通過；三項既存故事／字型校驗差異為曹操「我」改「孤」與行書缺「孤」字，討伐工作未變更該文案／字型。`npm test` 的 scripts 前置測試另有17項環境／缺失 .grok 參考檔失敗，故另外獨立執行 game suite 及聚焦97項（全部通過）。
